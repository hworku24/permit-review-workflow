Phase allowances

Each phase has its own allowance, and the phases add up to the council standard for that permit type. A discipline row overrides the general one for that discipline only.

Changing an allowance affects tasks opened after the change. Open tasks keep the allowance they opened with, because review_task.allowance_days is written when the task is created. A supervisor cannot make a reviewer late, or on time, by editing configuration underneath them.

What reaches open cases

The three changes on this screen behave differently, and the difference is deliberate in each case.

ChangeReachesWhy
Review discipline New applications only Routing is decided when intake is accepted. Opening a discipline on a case whose reviewers have already signed off would rewrite a decision made under the old rules.
Phase allowance Tasks opened afterwards The allowance is written onto the task when it opens. A supervisor cannot make a reviewer late, or on time, by editing configuration underneath them.
Required document New applications, and open ones at their next resubmission The checklist is rebuilt whenever a case arrives or comes back, so a new requirement catches work still in flight. A document already received is never reset.
Council standard Everything ever decided The compliance view applies the current standard to the whole history. This is the one that needs a second click.
